# Technology stack

| Layer | Technology | Role |
|---|---|---|
| Voice capture | Omi | Captures speech/transcripts |
| API | Python + FastAPI | Validation, orchestration, API docs |
| Agent reasoning | Lyzr | Distinct reasoning stages / agent workflow |
| Semantic memory | Qdrant Cloud | Retrieval across prior commitment statements |
| Frontend | HTML, CSS, vanilla JS | Responsive dashboard |
| Hosting | Render | Public Python web service |
| Tests | pytest | Basic extraction/conflict tests |

Each required tool must have a real, visible job in the final demo. Mentioning a service or displaying a label is not enough.
